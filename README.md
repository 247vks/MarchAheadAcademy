# March Ahead Academy

Local-first website and content platform for independent, source-led guidance on careers in India's Armed Forces.

## Current phase

Phase 1: local authority MVP. The site is intentionally marked `noindex, nofollow` until a production domain, review workflow, and canonical URL are ready.

## Run locally

```bash
npm install
npm run dev
```

## Product principles

- Explain, compare, verify, and prepare.
- Treat the current official notification and corrigenda as controlling.
- Distinguish the Indian Army, Indian Navy, and Indian Air Force from the Coast Guard, CAPFs, and other uniformed services.
- Show the source, review date, reviewer, and caveats for volatile facts.
- Never imply government affiliation or guarantee selection.
