PRIORITY 1 — NEXT IMPLEMENTATION RELEASE

0. Analytics robustness — measurement/frontend specialist.
   Source audit found no explicit SPA route page-view control/test; collection
   currently depends on GA enhanced-history settings. Verify actual behaviour,
   then implement consent-gated navigation tracking with no double counting.
   Consent timestamp validation accepts future savedAt values, and a long-lived
   tab lacks a timer/focus expiry check to disable an already loaded GA instance.
   Add finite/nonfuture validation, expiry synchronisation and regression tests.
   These are source-confirmed robustness gaps, not proof of current bad traffic.

1. Consultation clarity — conversion/editorial specialist.
   Evidence: app/consultation/page.tsx reaches contact choices without the
   confirmed online / appointment-only statement used on one-on-one-coaching.
   Add it beside contact options; explain the next step in plain language.
   Do not invent fees, duration, response times or session-provider promises.
   Acceptance: visible before contact options at 360px; no street address.

2. Keyboard navigation and landmarks — accessibility/frontend specialist.
   Evidence: shared SiteHeader has no skip link; several templates nest global
   header/footer inside main. Add first-focus Skip to content with real targets;
   review landmark structure rather than adding a nonfunctional anchor.
   Acceptance: keyboard-only traversal on each template, visible focus,
   no trap, working target and sensible landmarks. Then run automated a11y checks.

3. Canonical/schema/social consistency — technical SEO specialist.
   Evidence: GuideStructuredData concatenates supplied path; older guides pass
   slashless paths while canonical metadata uses trailing slashes. Normalise
   identifiers centrally without renaming URLs. Consultation inherits homepage
   social metadata; extend per-page checks to every route.
   Acceptance: one canonical per page, Article mainEntityOfPage matches it,
   page-specific og:url/title/description, parsed JSON-LD across export.
   Export audit counted 36 non-home pages inheriting homepage og:url.

4. Psychology connections and usable examples — editorial specialist.
   Link assessment, PPDT/TAT and repeater FAQ answers directly to their articles.
   Give each article a distinct tool: practice log, comparison, or relevance
   review. Label invented exercises illustrative; never imply real client data.
   Profile should link to academy psychology guidance, not call it his authored
   work. Remove repetitive editorial self-description, preserve material caveats.
   Acceptance: contextual links work, exercises differ, attribution remains true.
