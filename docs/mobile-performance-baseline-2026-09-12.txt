Image finding
On home, TES and SSB the CSS background aspirant-guidance-banner.png alone
transferred 1,836,528 bytes (file size1,836,228). It accounts for about87%
of each page's measured wire bytes. img-initiator bytes were0 because this
is a CSS image, not because the page downloaded no images.
Consultation/resources did not fetch this image in this run.

Highest-value practical optimization
components/contact-band.tsx:35 sets the large PNG as backgroundImage under
a 90-98% opaque olive gradient. Re-encode a suitably resized WebP/AVIF
variant and verify the appearance; use it instead of the PNG or consider
omitting this nearly-obscured decorative layer. This does not require any
editorial input. Do not promise LCP improvement: the measured LCP precedes
the large image completion; strongest demonstrated benefit is transfer
size and load completion, potentially data/battery cost.
